# ⛽ SmartFuel Monitor

An intelligent fuel stock monitoring platform developed using Python and Flask.

## 📌 Overview

SmartFuel Monitor is a web application designed to monitor fuel reservoirs in service stations.

The platform allows operators to:

- Monitor reservoir levels in real time
- Receive automatic low-level alerts
- Estimate fuel autonomy
- Visualize consumption history
- Manage stations and reservoirs through a dashboard
